# 宇瞳光电新闻详情页

## 文件结构
- `index.html`：新闻详情页
- `assets/style.css`：页面样式
- `assets/award.png`：奖杯与奖状
- `assets/venue.jpg`：会场照片
- `assets/ceremony.jpg`：颁奖合影
- `assets/presentation.jpg`：项目路演
- `assets/media-report.png`：杭州网报道截图

## 使用方式
直接打开 `index.html` 即可预览。部署时请保持 `index.html` 与 `assets` 目录的相对位置不变。

## 接入现有官网时建议调整
1. 将页头、页尾替换为现有官网公共组件。
2. 将导航中的 `#` 替换为实际栏目地址。
3. 根据现有 CMS 字段替换标题、发布日期、来源和正文。
4. 保留杭州网原报道链接及来源说明。
